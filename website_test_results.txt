   BUG #1 — CRITICAL: LLM Synthesis Failure (affects 35/35 queries)
   ---------------------------------------------------------------
   Error: "Analysis incomplete. LLM synthesis error: retries exhausted."
   Pattern: Appears on every single query without exception.
   Root Cause: The backend investment thesis pipeline successfully:
     (a) detects the company and resolves the ticker
     (b) classifies the setup quality as "Balanced"
     (c) assigns a decision label (HOLD)
     (d) assigns a thesis trend (WEAKENING/STABLE/etc.)
   ...but the LLM synthesis step (thesis_synthesizer.py) fails every time
   with "retries exhausted." This strongly indicates the LLM API key
   (OpenAI or Anthropic) is NOT configured in the Render production environment,
   or the model name has changed/been deprecated.
   Impact: 100% of analyses are non-functional. Users see a shell with
   metadata but zero analytical content.
   Fix Required: Verify OPENAI_API_KEY or ANTHROPIC_API_KEY is set in Render
   environment variables. Check Render service logs for the specific API error.

   BUG #2 — HIGH: React Hydration Errors on Every Page Load
   ---------------------------------------------------------
   Errors: React #418, #423, #425 firing on every page load (observed in
   browser console, 6+ instances per session).
   Pattern: Server-rendered HTML does not match client-rendered output.
   Impact: Silent — does not visibly break the UI for most users but indicates
   SSR/CSR mismatch that could cause rendering artifacts on some interactions.
   Fix Required: Identify server-only state (dates, randomness, env vars) leaking
   into the initial render. Wrap time-dependent or client-only content in
   useEffect or dynamic() with ssr:false.

   Result: Routed to MARKET QUESTION pipeline; no company detected.

   but without a company match it fell through to general finance.
   Fix: Add "JPMorgan" as an alias for JPMorgan Chase (JPM) in company aliases.
