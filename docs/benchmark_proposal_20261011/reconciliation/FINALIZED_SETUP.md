## Reproduce offline checks

```sh
PYTHONPATH=. python scripts/benchmark_registry_audit.py \
  --registry validation/issuer_registry.v2.json \
  --fixtures validation/fixtures.v2.json --strict-targets --json
PYTHONPATH=. python scripts/benchmark_company_quality.py \
  --registry validation/issuer_registry.v2.json --plan
PYTHONPATH=. python -m pytest -q --noconftest \
  tests/test_benchmark_cohort_setup.py \
  tests/test_benchmark_candidate_plan.py \
  tests/test_benchmark_admission_readiness.py \
  tests/test_benchmark_candidate_admission_builder.py \
  tests/test_benchmark_registry.py \
  tests/test_factual_citation_grading.py \
  tests/test_cap_tier_factual_benchmark.py \
  tests/test_company_quality_matrix.py tests/test_company_quality_review.py
```

No paid/live capture, full application regression, production retest, deployment
or account-setting change is part of this setup. The next execution step requires
separate live-capture authorization and must retain the held-out reservation and
all quality gates.

Validation result: **218 tests passed** across the nine focused suites above;
strict version 2 coverage audit passed with no deficits or integrity errors.
One pytest warning concerns the excluded application plugin setting `asyncio_mode`.
Negative checks reject changed approval scope, cap date/currency or value conflicts,
missing metadata, duplicate identities, holdout changes, altered questions, weakened
targets, execution flags and nested capture payloads. Matrix reconciliation confirms
600 missing captures and pending reviews; the plan CLI never calls capture.
