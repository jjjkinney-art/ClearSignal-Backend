# Evidence-backed financial monitoring

Numerical bull/bear boundaries in the completed pilot had no bound derivation.
PR282 withheld those generated investment views. This change restores a useful
partial answer only when admitted SEC comparisons establish a matched-period
operating-margin calculation through the existing financial-foundation producer.

The current reported margin is a monitoring benchmark, not a decision cutoff.
Its exact decimal value, formula, raw revenue and operating-income inputs,
filing references, currency, scope and reporting period remain inspectable.
No peer comparison, valuation conclusion, materiality boundary or expected
earnings effect follows from that calculation.

The source gate rebuilds the benchmark before persistence and again before
serialization. It does not trust model threshold objects or model citation IDs.
No matching calculation means the existing insufficient-evidence answer remains.
All generated bull/bear zones and unrelated investment prose are reset.

No new evidence retrieval, provider call, quota, timeout or pilot permission is
introduced. A threshold route that retrieves only filing metadata will still
abstain. Extending that route's input coverage requires separate work; this
change supplies the producer/admission contract without silently expanding the
approved pilot's threshold-route SEC allowance.

Offline validation on CPython 3.11.9: 74 producer/source/foundation/admission
tests passed. Router/latency checks and hosted CI are recorded in the PR.
Tests reject mutated facts, periods, scopes, currencies, citations and identity,
and verify repeated boundary application never restores generated cutoffs.
No live pilot or spending is authorized by this change.
