## Proposed acceptance criteria before execution

Retain the existing universal-quality requirements; freeze these operational
definitions before collecting the broader answers, not after seeing outcomes.

| Gate | Requirement |
| --- | --- |
| Useful, cited responses | At least 90% within each cap tier; also report and require 90% within each question family |
| Material numerical accuracy | At least 95%, using independently frozen reference facts and the existing factual grader |
| Material claim/source binding | 100%, with exact issuer, period, units and source; independently adjudicate entailment |
| Stop-ship defects | Zero fabricated material sources, issuer/period contamination, account leakage or issuer-level stop-ship failures |
| Denominators | All scheduled cases remain counted; missing, failed, gap-only and unreviewed cases cannot become useful-answer passes |
| Analytical usefulness | Existing responsiveness, reasoning, materiality, counterarguments, uncertainty and usefulness rubric; at least two independent blind reviewers, with disagreements resolved |

Binding is not entailment. Arithmetic agreement is not an independent truth check.
Partial answers require question-specific review rather than an automatic pass or
fail. An operating-margin benchmark can be valid and still fail to answer a
valuation-boundary question. Coverage/parity reporting must show failures instead
of hiding them inside an aggregate dominated by large companies. Signed-in and
international/source-family gates remain separate requirements for full launch.
