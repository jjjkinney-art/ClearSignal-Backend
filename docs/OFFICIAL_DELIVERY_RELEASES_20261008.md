## Retrieval gap and increment

The real September 26 Tesla investigation treated vehicle deliveries as a
confirmation metric for its competitive-advantage thesis. Its live comparison
retrieved only older periodic filings and correctly declined a directional claim.
Public-source inspection independently found an October 2 official release at:

https://ir.tesla.com/press-release/tesla-third-quarter-2026-production-deliveries-and-deployments

The official index is https://ir.tesla.com/press. The increment discovers links
from this index rather than pinning a quarterly URL, date or figure. Only exact
Tesla production/delivery release titles on the reviewed host are eligible;
company-compiled analyst consensus pages are excluded. It fetches at most one
index and two releases. Existing bounded public-document retrieval and the
router's ten-second evidence ceiling remain in force.

The adapter validates the visible issuer heading, publisher dateline, reporting
quarter and exact Production/Deliveries table layout. Total observations must
reconcile to Model 3/Y and Other Models, and parsed rows and headers must also
occur in visible document text. Missing, future, inconsistent, foreign-host or
ambiguous material yields a gap. A SHA-256-bound total-row quote, table columns,
table number, reporting period, issuer, unit and public URL accompany each claim.
Publication date is never replaced by retrieval time or the quarter end.

Evidence enters shared admission before all prompts and comparisons, retains
canonical citation IDs, and is not represented as a verified SEC fact. Current
release fetching is suppressed for historical point-in-time replay. Unsupported
issuers and questions incur no release request. Only the Tesla adapter is covered.

failures and source/date/period rejection; and check the shared API source view,
historical replay suppression and selected-comparison citation contract.
360 focused regression checks passed across retrieval, admission, source answers,
comparisons, ownership and launch security. Full repository collection succeeded
with 15,389 tests. The full pinned GitHub CI suite remains the merge gate.

Citation-contract readiness is not semantic entailment: vehicle deliveries alone
do not prove profitability, regional competitiveness or Supercharger advantage.
